## 2026-10-11 — Daily Swap Infrastructure Deployed

**New Feature:** Automatic giveaway value swap via dedicated `upcoming_flash_giveaway` metaobject.

- **What's new:** Operators stage next-day giveaway values (8 fields: flash_giveaway_start_date, flash_giveaway_end_date, flash_giveaway_timer_copy, flash_giveaway_desktop_banner, flash_giveaway_mobile_banner, pdp_images, mps_announcement_bar_texts, mps_homepage_announcement_bar_texts) in the `upcoming-flash-giveaway` entry.
- **Trigger:** Daily at 2:00 AM America/Chicago (3:00 PM Manila). Automatically adjusts for DST.
- **Automation:** GitHub Actions `monitor.yml` (every 15 min) + dedicated `giveaway-swap.yml` (once daily via cron-job.org, once created). Idempotent — multiple ticks apply the same daily gate using a persisted `state/giveaway-swap-date.txt` stamp.
- **Safety:** Staging entry fully cleared after each swap (prevents re-promotion of stale values). Live entry updated via sparse write (preserves 19 monthly fields untouched). Both mechanisms live-tested with Shopify Admin API v2026-10.
- **Telegram alerts:** Success on swap, optional "nothing staged" warning (scheduled run only), error on failure.

For full technical details, see `src/giveaway/swap.js`, `src/admin.js`, and `.github/workflows/giveaway-swap.yml`.
